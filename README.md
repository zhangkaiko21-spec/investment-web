# 投资分析与A股箱体策略系统

这是一个公开托管的投资分析项目，其中包含“周月箱体复利战法2.1”的自动行情、候选筛选和模拟账户模块。

## A股自动处理链路

系统通过 GitHub Actions 在A股交易日自动运行：

- 北京时间 09:35、10:35、13:35、14:35 更新行情与候选池
- 北京时间 14:50 执行尾盘模拟决策
- 东财全市场行情为主源
- 新浪全市场行情为备用源
- 腾讯行情用于最终候选交叉验证
- 东财历史K线为主源，腾讯历史K线为备用源
- 数据异常时停止新增模拟交易，不使用过期数据硬下单

自动输出文件位于 `data/a_share/`：

- `health.json`：数据源健康度与更新时间
- `market_summary.json`：市场涨跌与成交概况
- `candidates.json`：符合战法2.1的候选池
- `decision.json`：本轮模拟交易决定
- `account_state.json`：唯一模拟账本与当前持仓

核心程序位于：

```text
market_data/a_share_pipeline.py
market_data/strategy_config.json
.github/workflows/a-share-pipeline.yml
```

## 战法纪律

- 最近15个交易日和60个交易日均保持箱体结构
- 箱体振幅最多15%
- 优先箱体下沿，要求跌破后具备收复能力
- 最终候选必须通过双行情源价格核对
- 买入数量为100股整数倍
- 计入佣金、印花税和过户费
- 距离强制结算日3个交易日以内不再新开仓
- 达到5%-10%目标可提前结算
- 一个月到期，无论盈亏均强制结算并开启下一轮

## 安全说明

不要把任何真实API密钥写入公开仓库、JavaScript文件或README。前端调试密钥仅允许保存在本机浏览器的 `localStorage` 中，更推荐使用服务器端代理和GitHub Secrets。

仓库历史中曾出现过一段智谱API密钥。当前分支已清除，但历史提交仍可能保留旧值，因此必须在智谱控制台撤销并重新生成该密钥。

## 风险说明

系统只进行模拟交易和研究分析，不会连接券商或发送真实委托。公开行情与券商App不一致时，以券商App为最终执行依据。任何模拟结果都不构成投资建议。
